# THE THREE MAPS — PHASE II: TIMING & FUSION INTELLIGENCE

## Milestones
- **201.81K — Timing & Temporal Intelligence**
- **201.81L — Fusion Intelligence v2**
- **201.81M — Explanation & Interpretation v2**

## 201.81K
Temporal windows are explicit evidence objects. They support ACTIVE, UPCOMING,
EXPIRED, UNAVAILABLE and INVALID states. Boundaries are inclusive. Temporal
activation cannot create semantic evidence; it only qualifies already established
signals. Temporal compatibility is reported separately from semantic strength.

## 201.81L
Fusion v2 preserves the canonical Fusion Strength formula. Temporal salience and
expected temporal coverage are diagnostic inputs and are never silently multiplied
into Fusion Strength. Missing temporal data is unavailable, not zero evidence.

## 201.81M
Explanation v2 adds timing/readiness context while preserving the evidence-first
contract. It does not recalculate scores, create poles, infer contradiction, convert
strength to probability, diagnose, or make deterministic predictions.

## Phase-II invariants
1. Timing cannot manufacture a signal.
2. Missing timing is unavailable, not negative evidence.
3. Temporal salience is not probability.
4. Fusion Strength remains distinct from Data Confidence and temporal salience.
5. Explanation can synthesize only validated upstream outputs.
6. S6/S7 ownership remains with the Contradiction Engine.
