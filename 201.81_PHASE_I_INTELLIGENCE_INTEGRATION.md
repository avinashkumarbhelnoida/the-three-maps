# THE THREE MAPS — Phase I: Intelligence Integration

## Scope

Phase I closes milestones **201.81G–201.81J** and establishes the common
cross-map intelligence boundary between Astrology, Numerology and Palmistry.

### 201.81G — Cross-Map Signal Mapping & Ontology Integration

- Added `engines/cross_map.py` mapping-resolution boundary.
- Active source-variable mappings are resolved only through the explicit
  `SignalMappingRegistry`.
- Zero active mappings are reported as `UNAVAILABLE` rather than negative
  evidence.
- Multiple active mappings are reported as `INVALID` because they are
  ambiguous.
- Registry records are converted to the existing `SignalMapping` contract;
  semantic mapping remains configuration-owned.

### 201.81H — Full Three-Map Evidence Normalization

- Added a common `NormalizedMapSignal` contract.
- Active, permitted signals are normalized by Theme/Sub-Theme/Axis and retain
  source system, evidence clusters, temporal scope and context scope.
- Inactive, blocked, not-applicable and wrong-target signals are excluded from
  downstream scoring without zero filling.
- Added `MapUnit` as the normalized map-level Relationship Unit.
- System Score status is preserved; only `EVALUATED` and `PARTIAL` score-bearing
  systems enter relationship processing.

### 201.81I — Advanced Convergence & Relationship Integration

- Added `normalize_map_units()` and `evaluate_phase1_relationship()`.
- Relationship processing now consumes a common cross-map contract rather than
  map-specific structures.
- Existing S0–S5 semantics remain authoritative.
- S3/S4/S5 are never created by arithmetic majority alone.
- Independence and evidence-cluster separation remain explicit qualifiers.

### 201.81J — Advanced Contradiction / VMO Integration

- Directional opposition streams are explicitly separated into A and B groups.
- Aggregate axis polarity is not used to declare contradiction.
- Contradiction is delegated to the dedicated Contradiction Engine.
- Duplicate EvidenceCluster IDs cannot satisfy the independent evidence
  requirement for formal opposition.
- Context resolution and temporal compatibility remain formal gates.
- S6/S7 ownership remains exclusively with the Contradiction Engine.
- Only S7 is eligible for a Fusion contradiction penalty.

## Phase-I invariants

1. Missing mapping ≠ negative evidence.
2. Unavailable ≠ zero.
3. Invalid ≠ zero.
4. PARTIAL scores remain numeric and are not multiplied by coverage.
5. A dual-pole signal is not itself a contradiction.
6. Two-vs-one is not majority-wins logic.
7. Contradiction requires distinguishable opposing evidence streams.
8. Same semantic level and temporal compatibility are required for formal
   contradiction.
9. Context resolution prevents formal contradiction.
10. Explanation remains downstream and cannot create evidence.
