# 201.80G — GOLDEN DATASET

## Purpose
The Golden Dataset is the canonical regression truth set for THE THREE MAPS. It stores named scenarios with expected state/result constraints so future methodology, calculation, ontology, and explanation changes can be regression-tested.

## Dataset
- Dataset ID: `GDS-001`
- Dataset Version: `GD-0.1.0`
- Cases: 25
- Categories: relationship, contradiction, axis, system_score, fusion

## Coverage
The dataset includes S0–S5 relationship states, S6/S7 contradiction states, one-sided support, dominance, meaningful tie, balanced and insufficient axis outcomes, EVALUATED/PARTIAL/UNAVAILABLE/INVALID system-score states, the canonical Fusion Golden Test, and adversarial contradiction protections.

## Golden rules
1. Missing evidence is not negative evidence.
2. UNAVAILABLE and INVALID are not numeric score-bearing states.
3. PARTIAL is numeric and qualified; coverage does not multiply the score.
4. S6 and S7 are mutually exclusive.
5. Context, temporal, semantic, and duplicate-evidence protections remain active.
6. The canonical Fusion Golden Test remains fixed at `77.35` HIGH for the specified inputs.
7. Dataset versions are immutable; corrections create a new dataset version.
