# 201.83 — LOCAL BACKEND SMOKE TEST

Purpose: provide a small, safe backend wrapper around the frozen V1 intelligence core so the product can be tested locally before production backend work.

## Included
- Local development authentication (`local-dev-token`) only when no token registry is configured and environment is `development`.
- `GET /v1/me` principal check.
- `POST /v1/readings` product-facing alias for the existing immutable analysis pipeline.
- User question persisted in the immutable input snapshot.
- Frontend sends the local development bearer token.
- Local SQLite database and `run_local.py` launcher.

## Run
```bash
pip install -e .
python run_local.py
```
Then open `http://127.0.0.1:8000/`.

## What can be tested now
- Name + date → live Numerology result.
- Date/time + latitude/longitude → live Astrology result.
- Selecting both maps → both live map calculations when required inputs exist.
- Question capture and immutable persistence.
- Owner-isolated analysis retrieval and lineage.

## Deliberately not included yet
- Production identity provider.
- Real palm-image object storage lifecycle.
- Full question taxonomy.
- Full reading orchestration/fusion endpoint from raw user data.
- Payments/subscriptions.

These remain future product-backend work and do not alter the frozen V1 calculation rules.
